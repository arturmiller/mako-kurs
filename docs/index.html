Die Lernreise

Jede Lektion vermittelt genau ein mentales Modell. Das Architektur-Labor überträgt es auf dasselbe fiktive EVU-System. Fortschritt bleibt lokal in deinem Browser.

Leitidee

Modelliere fachliche Tatsachen, nicht Nachrichten. Eine UTILMD kann eine Tatsache transportieren; sie ist nicht die Tatsache selbst. Diese Trennung macht dein System revisionsfähig und offen für neue Transportwege wie APIs.
